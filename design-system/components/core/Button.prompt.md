The capsule button — every call to action in Libera Cash, at three sizes and six skins.

```jsx
<Button variant="dark" glyph="↗">Send</Button>
<Button variant="primary" icon="plus">Add Enhancements</Button>
```

Variants: `primary` (green, forest text — the default CTA), `dark` (forest, white text —
pairs with primary on the hero card), `secondary` (white + hairline border),
`ghost` (transparent), `onAccent` (white capsule for sitting on the green hero card or
imagery), `danger`.
Sizes `sm` 34px · `md` 42px · `lg` 50px. Green darkens on hover, forest lightens.
Use `glyph` for the typographic arrows (Send ↗, Deposit ↓); use `icon`/`iconAfter` for Lucide.
