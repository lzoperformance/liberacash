Outline icon glyph — the only way icons enter a Libera Cash surface.

```jsx
<Icon name="wallet" size={20} />
```

Requires the Lucide UMD script on the page:
`<script src="https://unpkg.com/lucide@0.454.0/dist/umd/lucide.js"></script>`.
Colour comes from `currentColor` — set it on the parent, never on the icon.
Sizes: 18 table rows · 20 controls/nav · 24 standalone · 28 circular tiles.
Never fill an icon and never mix in a filled set.
