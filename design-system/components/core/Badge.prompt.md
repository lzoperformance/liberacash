One-word status pill, and the delta chip that sits beside KPI figures.

```jsx
<Badge tone="success">Completed</Badge>
<Badge tone="pending">Pending</Badge>
<Badge tone="success" size="sm" icon="trending-up" delta="+1.78%" />
```

Status copy is always a single word: Completed · Pending · Active. Red (`pending`) is the only
alarming colour in the system and it is still a pale wash, never a solid red block.
